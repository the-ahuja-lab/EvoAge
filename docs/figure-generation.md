# 12 — Figure Generation

The plotting notebook is
[`pipeline/12_ploting/all_figures.ipynb`](https://github.com/the-ahuja-lab/EvoAge/blob/main/pipeline/12_ploting/all_figures.ipynb).
It contains plotting cells for Main Figures 1, 2, 4, and 5 and Supplementary
Figures 1–7. Figure 3 is a schematic and is not generated by this notebook.

## Scope

The notebook primarily converts prepared CSV, NumPy, JSON, Excel, and other
upstream outputs into manuscript figures. It does not rerun expensive pipeline
steps such as knowledge-graph construction, model training, full entity
ranking, randomization experiments, Bayesian model fitting, or bootstrap
evaluation. Individual plotting cells may perform the lightweight data
preparation, normalization, descriptive statistics, or statistical tests
needed for their panel.

The figure inputs include graph-composition summaries, training and evaluation
tables, hypothesis verdicts, comparative benchmark results, yeast thermal-screen
results, BACE1 validation data, and type-compatible ranking and null-model
results. The detailed input categories are listed in the
[`pipeline/12_ploting` README](https://github.com/the-ahuja-lab/EvoAge/blob/main/pipeline/12_ploting/README.md).

## Reproducing a panel

1. Open `pipeline/12_ploting/all_figures.ipynb` in JupyterLab or another
   compatible notebook environment.
2. Find the Markdown heading for the required figure and panel.
3. Check that the input paths used by that cell exist in the local environment.
4. Run the panel cell and any setup cell immediately above it on which it
   depends.

The notebook uses common scientific Python packages such as NumPy, pandas,
Matplotlib, and SciPy, with additional libraries imported by particular cells.
Its saved outputs allow the current figures to be inspected without rerunning
the notebook.

## Path portability

Several cells retain absolute `/storage/Arushi/...` or `/storage3/arushis/...`
paths from the analysis environment. These paths are not portable. To rerun a
panel elsewhere, change the relevant path variable to the corresponding local
pipeline output. A saved notebook output can still be viewed when its original
input path is unavailable.
